##  Sobre el proyecto

**Mi Ahorro 100** es una aplicación web progresiva (PWA) diseñada para ayudarte a construir un hábito de ahorro sólido mediante un sistema de **100 depósitos progresivos** distribuidos equitativamente a lo largo de un año.

La filosofía es simple: **pequeños depósitos constantes generan grandes resultados**. Cada semana realizas 2 depósitos que suman exactamente **$101.000**, haciendo el proceso predecible, manejable y motivador.

>  **Meta total:** $5.050.000 COP en 52 semanas

## ✨ Características

### 🎯 Funcionalidades principales

- 📱 **Diseño mobile-native** - Interfaz optimizada para móviles
-  **4 secciones** - Inicio, Calendario, Estadísticas y Configuración
- 📊 **Progreso visual** - Anillo de progreso animado en tiempo real
- 📅 **Calendario inteligente** - Depósitos agrupados por mes
- ️ **Configurable** - Elige cuándo empezar tu plan
- 💾 **Persistencia local** - Tu progreso se guarda automáticamente
- 📲 **Instalable** - Funciona como app nativa
- 🌐 **Modo offline** - Funciona sin internet

### 🎲 Sistema de ahorro inteligente

El sistema usa **pares equilibrados** para mantener la constancia:

    Semana 1:  $1.000  + $100.000 = $101.000
    Semana 2:  $2.000  + $99.000  = $101.000
    Semana 3:  $3.000  + $98.000  = $101.000
       ...
    Semana 50: $50.000 + $51.000  = $101.000
    ─────────────────────────────────────
    Total: 50 pares × $101.000 = $5.050.000

✅ **Ventajas:**
- Monto semanal constante y predecible
- Combina depósitos pequeños y grandes
- 2 semanas de descanso al final
- Promedio mensual: ~$420.833

## 🚀 Cómo usar

### Opción 1: Versión online

Visita: https://tu-usuario.github.io/mi-ahorro-100/

### Opción 2: Instalar como app

**iPhone (Safari):**
1. Abre la URL en Safari
2. Toca Compartir (⬆️)
3. "Agregar a pantalla de inicio"

**Android (Chrome):**
1. Abre la URL en Chrome
2. Menú ⋮
3. "Agregar a la pantalla principal"

### Opción 3: Localmente

    git clone https://github.com/tu-usuario/mi-ahorro-100.git
    cd mi-ahorro-100
    # Abre index.html en tu navegador
